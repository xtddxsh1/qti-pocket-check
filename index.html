Question file inventory

The report includes archive/file names, item IDs, counts, and diagnostics. It excludes question text, but filenames and IDs can still be sensitive. Review it before sharing.

A useful first look, with clear limits.

What it checks

  • Root or nested imsmanifest.xml.
  • Local manifest references to files in the ZIP.
  • QTI 1.x / 1.2-style and QTI 2.x XML, with item counts.
  • QTI 1.x response_lid elements missing rcardinality.

What it cannot tell you

  • Whether Canvas or another LMS will accept the package.
  • Whether every question or answer is correct.
  • Whether the package passes a full QTI schema or accessibility audit.
  • Whether remote files or references affected by xml:base exist.

No files are changed. Nothing is submitted to an LMS. XML with DTD/entity declarations, encrypted ZIPs, and ZIP64 archives are rejected.
